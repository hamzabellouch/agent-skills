# Ordinary Differential Equations (ODEs)

## Domain
Equations involving derivatives of one variable.

## Core Concepts
- Order, linearity, homogeneity
- Initial value vs. boundary value problems
- Existence and uniqueness (Picard–Lindelöf)
- Systems of ODEs, phase portraits
- Sturm–Liouville theory

## Key Methods
- Separation of variables
- Integrating factors
- Characteristic equation for linear ODEs
- Laplace transforms
- Power series solutions (Frobenius)

## Canonical Examples
- y' = ky → y = Ce^{kx}.
- y'' + y = 0 → y = A cos x + B sin x.
- Solve y' + y = e^{-x} via integrating factor.

## Common Pitfalls
- Forgetting constants of integration
- Misapplying Laplace transform initial conditions
- Confusing homogeneous vs. nonhomogeneous solutions

Calculus, PDEs, Numerical Methods
