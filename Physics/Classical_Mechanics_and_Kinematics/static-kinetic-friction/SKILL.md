# Static and Kinetic Friction

**ID:** `mech.dynamics.friction`  
**Domain:** Mechanics → Dynamics  
**Difficulty:** 2/5

## Prerequisites
- mech.dynamics.free_body

## Core Concepts
- coefficient of friction
- static friction
- kinetic friction
- impending motion
- rolling friction

## Key Equations
$$
f_s \le \mu_s N
$$
$$
f_k = \mu_k N
$$

## Methods
- Compute normal force first
- Check if static friction is sufficient to prevent motion
- Switch to kinetic friction once sliding starts

## Typical Problem Types
- Block on a horizontal surface pulled by a force
- Block on an incline at the angle of repose
- Two stacked blocks

## Common Pitfalls
- Treating static friction as always equal to \mu_s N
- Forgetting that static friction adjusts to the applied force
