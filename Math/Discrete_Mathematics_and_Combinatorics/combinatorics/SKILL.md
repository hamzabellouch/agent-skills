# Combinatorics

## Domain
Counting and arrangement.

## Core Concepts
- Permutations, combinations
- Binomial and multinomial coefficients
- Inclusion–exclusion
- Generating functions
- Partitions, Stirling numbers

## Key Methods
- Stars and bars
- Inclusion–exclusion principle
- Recursion + generating functions
- Double counting

## Canonical Examples
- C(n,k) = n!/(k!(n-k)!).
- Number of onto functions = inclusion–exclusion.
- Catalan numbers: C_n = (1/(n+1))·C(2n,n).

## Common Pitfalls
- Counting ordered vs. unordered
- Overcounting in inclusion–exclusion
- Forgetting empty set / empty arrangement

## Related Skills
Discrete Math, Probability, Graph Theory
