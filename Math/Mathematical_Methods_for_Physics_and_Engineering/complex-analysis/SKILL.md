# Complex Analysis

**ID:** `math.complex_analysis`  
**Domain:** Mathematics → Analysis  
**Difficulty:** 4/5

## Prerequisites
- math.calculus.integrals

## Core Concepts
- analytic functions
- Cauchy-Riemann
- contour integrals
- residues
- Laurent series

## Key Equations
$$
\oint f(z)\,dz = 2\pi i\sum\text{Res}(f,z_k)
$$

## Methods
- Check analyticity
- Use Cauchy's theorem
- Compute residues for real integrals

## Typical Problem Types
- Real integrals via residues
- Conformal mapping
- Dispersion relations

## Common Pitfalls
- Applying Cauchy's theorem to non-analytic functions
- Wrong residue at higher-order poles
