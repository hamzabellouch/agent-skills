# Set Theory

## Domain
Foundations of mathematics via sets.

## Core Concepts
- Sets, subsets, power sets
- Unions, intersections, complements
- Relations, functions, orderings
- Cardinality, countability
- Axiom of Choice, ZFC

## Key Methods
- Cantor's diagonal argument
- Transfinite induction
- Ordinals and cardinals
- Forcing (advanced)

## Canonical Examples
- |ℕ| = |ℚ| < |ℝ|.
- Power set of S has 2^{|S|} elements.
- Russell's paradox: no set of all sets.

## Common Pitfalls
- Naive comprehension leads to paradoxes
- Confusing ∈ with ⊆
- Assuming AC always holds constructively

## Related Skills
Logic, Topology, Category Theory
