# Two-Dimensional Collisions

**ID:** `mech.momentum.2d_collisions`  
**Domain:** Mechanics → Momentum  
**Difficulty:** 3/5

## Prerequisites
- mech.momentum.conservation

## Core Concepts
- 2D momentum
- scattering angle
- vector conservation
- glancing collision

## Key Equations
$$
\sum p_x = \text{const}
$$
$$
\sum p_y = \text{const}
$$

## Methods
- Write conservation separately for x and y
- Use energy conservation only if elastic
- Use CM frame or lab frame as convenient

## Typical Problem Types
- Billiard ball scattering
- Two-car intersection crash
- Particle scattering

## Common Pitfalls
- Conserving total momentum but not components
- Forgetting the angles of the final velocities

- mech.momentum.elastic
- qm.scattering.theory
