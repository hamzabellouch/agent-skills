# Mathematical Logic

## Domain
Formal reasoning and proof.

## Core Concepts
- Propositional and predicate logic
- Quantifiers, free/bound variables
- Proof systems: natural deduction, sequent calculus
- Soundness, completeness
- Gödel's incompleteness theorems

## Key Methods
- Truth tables
- Resolution
- Model theory, proof theory
- Compactness theorem

## Canonical Examples
- ¬(P ∧ Q) ≡ ¬P ∨ ¬Q (De Morgan).
- ∀x P(x) → ¬∃x ¬P(x).
- Gödel: any consistent formal system containing arithmetic is incomplete.

## Common Pitfalls
- Confusing syntax with semantics
- Misusing quantifier order: ∀∃ ≠ ∃∀
- Ignoring scope of negation

## Related Skills
Set Theory, Discrete Math, Category Theory
