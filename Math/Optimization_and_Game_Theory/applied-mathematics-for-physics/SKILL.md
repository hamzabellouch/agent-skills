# Applied Mathematics for Physics

## Domain
Mathematical tools used in theoretical physics.

## Core Concepts
- Lagrangian and Hamiltonian mechanics
- Variational principles
- Tensor calculus, index notation
- Special and general relativity math
- Quantum mechanics formalism (Hilbert spaces)
- Statistical mechanics (partition functions)

## Key Methods
- Euler–Lagrange equations
- Noether's theorem (symmetry → conservation)
- Fourier analysis for fields
- Path integrals (conceptual)
- Renormalization group (advanced)

## Canonical Examples
- L = T - V; d/dt(∂L/∂q̇) - ∂L/∂q = 0.
- Einstein field equations: G_μν = 8πG T_μν.
- Schrödinger: iℏ ∂ψ/∂t = Ĥψ.

## Common Pitfalls
- Index mistakes in tensor equations
- Confusing covariant and contravariant
- Ignoring units and dimensional analysis

## Related Skills
Differential Geometry, Functional Analysis, PDEs
