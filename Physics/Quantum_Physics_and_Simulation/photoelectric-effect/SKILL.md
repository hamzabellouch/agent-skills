# Photoelectric Effect

**ID:** `qm.found.photoelectric`  
**Domain:** Quantum Mechanics → Foundations  
**Difficulty:** 2/5

## Prerequisites
- qm.found.blackbody_planck

## Core Concepts
- photon
- work function
- stopping potential
- threshold frequency
- Einstein's equation

## Key Equations
$$
K_{max} = h\nu - \phi
$$
$$
eV_s = h\nu - \phi
$$

## Methods
- Use energy conservation for a single photon-electron event
- Find threshold frequency: h
u_0 = \phi
- Interpret stopping potential vs frequency graphs

## Typical Problem Types
- Stopping potential measurement
- Threshold wavelength for a metal
- Kinetic energy of emitted electrons

## Common Pitfalls
- Thinking intensity changes K_max
- Forgetting the work function
