# Newton's Law of Universal Gravitation

**ID:** `mech.gravitation.newton_law`  
**Domain:** Mechanics → Gravitation  
**Difficulty:** 2/5

## Prerequisites
- mech.dynamics.newton_laws

## Core Concepts
- universal gravitation
- inverse square law
- gravitational constant
- superposition of fields

## Key Equations
$$
F = G\frac{m_1 m_2}{r^2}
$$
$$
G \approx 6.674\times10^{-11}\ \text{N m}^2/\text{kg}^2
$$

## Methods
- Use the inverse-square law
- Add vector fields for multiple masses
- Use shell theorem for spherical bodies

## Typical Problem Types
- Two-body attraction
- Three-mass configuration
- Field inside/outside a shell

## Common Pitfalls
- Adding forces as scalars
- Forgetting that G is universal but g depends on the planet
