# Angular Kinematics

**ID:** `mech.rotation.angular_kinematics`  
**Domain:** Mechanics → Rotation  
**Difficulty:** 2/5

## Prerequisites
- mech.kinematics.constant_acceleration

## Core Concepts
- angular position
- angular velocity
- angular acceleration
- angular suvat

## Key Equations
$$
\omega = \frac{d\theta}{dt}
$$
$$
\alpha = \frac{d\omega}{dt}
$$
$$
\omega^2 = \omega_0^2 + 2\alpha\Delta\theta
$$

## Methods
- Use the angular analogues of suvat
- Relate linear to angular via r
- Choose a convenient axis

## Typical Problem Types
- Rotating wheel
- Pulley with angular acceleration
- Disk spinning up

## Common Pitfalls
- Mixing linear and angular quantities
- Forgetting the sign of \omega
