# Physics Problem-Solving Methodology

## The 7 steps
1. **Understand** – restate the question, list givens and unknowns with units, draw a diagram.
2. **Model** – decide approximations (point mass, frictionless, small angle, steady state, non-relativistic) and justify them.
3. **Principle** – choose the governing law: Newton, energy, momentum, angular momentum, Maxwell, thermodynamic laws, Schrödinger, symmetry/conservation. Prefer conservation laws when forces/path details are messy.
4. **Equations** – write general equations first, then specialize; count equations vs unknowns.
5. **Solve symbolically** – isolate the target variable before substituting numbers; look at structure for insight.
6. **Compute** – insert SI values; keep 3 significant figures; show units through the calculation.
7. **Check** – dimensional consistency, order of magnitude, limiting cases, sign, alternative method, physical reasonableness.

## Communicating
- Give the final answer in a sentence with units and uncertainty if any.
- Explain "why this approach" briefly; mention common wrong approaches.
- For conceptual questions use analogies, thought experiments, and one clear equation.

## Strategies by situation
- Stuck → simplify (special case), draw, change variables, look for symmetries, work backward from the target.
- Multiple objects → separate free-body diagrams; link by constraints.
- Time-dependent → identify timescales; steady state vs transient.
- Probability/quantum → list basis states, compute amplitudes first.

## Common errors
Unit mix-ups (cm vs m, degrees vs radians in calculators), sign conventions, forgetting vector nature, using the wrong reference point for torque, treating averages as instantaneous values.
