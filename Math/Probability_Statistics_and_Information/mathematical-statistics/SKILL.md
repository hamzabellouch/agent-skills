# Statistics

## Domain
Inference from data.

## Core Concepts
- Descriptive stats: mean, median, variance, quantiles
- Estimators: bias, variance, MSE
- Confidence intervals, hypothesis testing
- p-values, power, type I/II errors
- Regression, ANOVA

## Key Methods
- Maximum likelihood estimation
- Method of moments
- t-test, χ²-test, F-test
- Bootstrap and permutation tests
- Bayesian inference (priors, posteriors)

## Canonical Examples
- MLE of Normal mean = sample mean.
- 95% CI for μ: x̄ ± 1.96·σ/√n.
- OLS regression: β = (XᵀX)⁻¹Xᵀy.

## Common Pitfalls
- p-hacking, multiple comparisons
- Confusing statistical with practical significance
- Ignoring assumptions (normality, independence)

## Related Skills
Probability, Linear Algebra, Machine Learning
