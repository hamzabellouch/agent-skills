# Centripetal Force Applications

**ID:** `mech.dynamics.centripetal`  
**Domain:** Mechanics → Dynamics  
**Difficulty:** 3/5

## Prerequisites
- mech.kinematics.circular_uniform
- mech.dynamics.free_body

## Core Concepts
- centripetal force
- radial net force
- banked curve
- vertical circle

## Key Equations
$$
\sum F_{radial} = \frac{mv^2}{r}
$$
$$
v_{min} = \sqrt{gR}\ \text{(vertical circle top)}
$$

## Methods
- Identify the physical force(s) acting radially
- Set their resultant equal to mv^2/r
- Check the minimum-speed condition

## Typical Problem Types
- Car on a flat curve (friction provides F_c)
- Banked curve without friction
- Vertical loop-the-loop

## Common Pitfalls
- Thinking 'centrifugal force' pushes outward in an inertial frame
- Using mv^2/r as an extra force instead of a net force
