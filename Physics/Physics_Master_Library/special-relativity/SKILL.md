# Special Relativity

## Postulates
Laws of physics are identical in all inertial frames; c is the same for all observers.

## Formulas
- γ = 1/sqrt(1 - v²/c²), β = v/c
- Lorentz boost (x-direction): x' = γ(x - vt), t' = γ(t - vx/c²)
- Time dilation Δt = γΔτ (τ = proper time); length contraction L = L0/γ
- Velocity addition u' = (u - v)/(1 - uv/c²)
- Relativistic Doppler f_obs = f sqrt((1+β)/(1-β)) (approaching); transverse Doppler f = f0/γ
- Momentum p = γmv; energy E = γmc²; E² = (pc)² + (mc²)²; K = (γ-1)mc²; photon E = pc
- Four-vectors: x^μ = (ct, x), p^μ = (E/c, p), invariant interval s² = c²t² - x² ; p^μ p_μ = m²c²
- Threshold energy for particle production: invariant mass s = (ΣE)² - |Σp|²c²
- Relativistic force F = dp/dt; acceleration a = F/(γ³m) parallel, F/(γm) perpendicular
- Constant proper acceleration (hyperbolic motion): x = (c²/a)(cosh(aτ/c) - 1)
- Electromagnetism transforms: E'∥ = E∥, E'⊥ = γ(E + v×B)⊥

## Paradoxes
- Twin: the traveling twin changes frames (accelerates) → ages less.
- Ladder/barn: simultaneity is frame dependent; no contradiction once relativity of simultaneity is used.

## Method
1. Define events with coordinates in one frame.
2. Use invariants (interval, invariant mass) to avoid transformation errors.
3. Use conservation of four-momentum in collisions/decays.
4. Check β→0 reproduces Newtonian result.
