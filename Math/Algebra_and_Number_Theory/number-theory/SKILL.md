# Number Theory

## Domain
Properties of integers.

## Core Concepts
- Divisibility, primes, unique factorization
- Congruences, modular arithmetic
- Diophantine equations
- Quadratic residues, Legendre symbol
- Riemann zeta function, analytic NT

## Key Methods
- Euclidean algorithm
- Chinese Remainder Theorem
- Fermat's little theorem, Euler's theorem
- Quadratic reciprocity
- Sieve methods

## Canonical Examples
- Solve x ≡ 2 (mod 3), x ≡ 3 (mod 5) → x ≡ 8 (mod 15).
- Prove infinitely many primes (Euclid).
- Wilson: (p-1)! ≡ -1 (mod p) for prime p.

## Common Pitfalls
- Assuming unique factorization in all rings
- Misapplying Fermat when modulus isn't prime
- Ignoring coprimality conditions

## Related Skills
Abstract Algebra, Cryptography, Combinatorics
