# Complex Analysis

## Domain
Functions of a complex variable.

## Core Concepts
- Complex numbers, polar form, Euler's formula
- Analytic/holomorphic functions
- Cauchy–Riemann equations
- Contour integrals, residues
- Laurent series, singularities

## Key Methods
- Cauchy integral theorem and formula
- Residue theorem for real integrals
- Conformal mappings
- Argument principle

## Canonical Examples
- e^{iπ} + 1 = 0.
- ∮ dz/z around |z|=1 equals 2πi.
- ∫_{-∞}^{∞} dx/(1+x²) = π via residues.

## Common Pitfalls
- Assuming all functions are holomorphic
- Miscounting residues inside contour
- Ignoring branch cuts for log/sqrt

## Related Skills
Real Analysis, Differential Equations, Number Theory
