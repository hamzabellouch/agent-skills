# Single-Variable Calculus

## Domain
Limits, derivatives, integrals of one-variable functions.

## Core Concepts
- Limits, continuity, differentiability
- Derivatives: rules, chain rule, implicit differentiation
- Integrals: Riemann, fundamental theorem
- Sequences, series, convergence tests
- Taylor and Maclaurin series

## Key Methods
- L'Hôpital's rule
- Integration by parts, substitution, partial fractions
- Ratio/root/comparison tests
- Taylor expansion around a point

## Canonical Examples
- d/dx [x² sin x] = 2x sin x + x² cos x.
- ∫₀¹ x² dx = 1/3.
- e^x = Σ xⁿ/n! converges everywhere.

## Common Pitfalls
- Applying L'Hôpital when limit isn't indeterminate
- Forgetting +C on indefinite integrals
- Misusing convergence tests on divergent series
