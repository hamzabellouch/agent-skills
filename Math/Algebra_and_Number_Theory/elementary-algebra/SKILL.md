# Elementary Algebra

## Domain
Symbolic manipulation of equations and inequalities.

## Core Concepts
- Variables, expressions, polynomials
- Linear and quadratic equations
- Systems of equations
- Exponents and logarithms

## Key Methods
- Factoring (difference of squares, grouping)
- Quadratic formula: x = (-b ± √(b²-4ac)) / 2a
- Completing the square
- Substitution and elimination
- Logarithm rules: log(ab)=log a + log b

## Canonical Examples
- Solve x² - 5x + 6 = 0 → x ∈ {2, 3}.
- Solve system: x+y=5, 2x-y=1 → x=2, y=3.
- Expand (a+b)³ = a³ + 3a²b + 3ab² + b³.

## Common Pitfalls
- Forgetting to flip inequality sign when multiplying by negative
- Extraneous roots from squaring both sides
- Invalid log arguments (≤0)

## Related Skills
Linear Algebra, Calculus, Number Theory
