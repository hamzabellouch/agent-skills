# Relativistic Two-Body Problem

**ID:** `rel.general.two_body`  
**Domain:** Relativity → General  
**Difficulty:** 5/5

## Prerequisites
- rel.general.schwarzschild
- mech.momentum.center_of_mass

## Core Concepts
- effective potential
- ISCO
- test-particle motion
- Keplerian vs relativistic orbits

## Key Equations
$$
V_{eff}(r) = -\frac{GMm}{r} + \frac{L^2}{2mr^2} - \frac{GML^2}{mc^2r^3}
$$

## Methods
- Write the effective potential
- Find ISCO from extremizing V_eff
- Compute precession per orbit

## Typical Problem Types
- Innermost stable circular orbit (ISCO)
- Perihelion precession
- Binary pulsar decay

## Common Pitfalls
- Using Newtonian effective potential
- Forgetting the relativistic correction term
