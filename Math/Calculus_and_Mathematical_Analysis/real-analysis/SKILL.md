# Real Analysis

## Domain
Rigorous foundations of calculus on ℝ.

## Core Concepts
- Completeness, supremum, infimum
- Sequences, Cauchy sequences, convergence
- Open, closed, compact sets
- Continuity, uniform continuity
- Riemann and Lebesgue integration
- Measure theory basics

## Key Methods
- ε–δ proofs
- Bolzano–Weierstrass theorem
- Heine–Borel theorem
- Monotone convergence, dominated convergence
- Construction of ℝ via Dedekind cuts or Cauchy sequences

## Canonical Examples
- Prove sup(0,1) = 1.
- Every continuous function on [a,b] is uniformly continuous.
- Cantor set is uncountable, measure zero.

## Common Pitfalls
- Confusing pointwise with uniform convergence
- Assuming continuity implies differentiability
- Ignoring measure-zero exceptions in Lebesgue theory

Topology, Complex Analysis, Functional Analysis
