# Math Skills Library

28 Agent Skills covering mathematics from arithmetic to abstract algebra, analysis, topology, probability, statistics, optimization, numerical computation and ML theory. Each folder has a `SKILL.md` (YAML frontmatter + instructions); several include tested Python `scripts/`.

**Start with `math-master`**, which routes any question to the right specialist skill.
