# Ordinary Differential Equations

**ID:** `math.odes`  
**Domain:** Mathematics → Differential Equations  
**Difficulty:** 3/5

## Prerequisites
- math.calculus.integrals

## Core Concepts
- first/second-order ODEs
- linear ODEs
- separable equations
- homogeneous/inhomogeneous
- characteristic equation

## Key Equations
$$
y' + p(x)y = q(x)
$$
$$
y'' + ay' + by = 0
$$

## Methods
- Identify order and linearity
- Use integrating factor for first order
- Use characteristic equation for linear constant-coefficient

## Typical Problem Types
- Exponential growth/decay
- Damped oscillator
- RC circuit

## Common Pitfalls
- Forgetting the particular solution for inhomogeneous equations
- Sign errors in characteristic roots
