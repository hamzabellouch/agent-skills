# Analytic Geometry

## Domain
Geometry via coordinates.

## Core Concepts
- Cartesian and polar coordinates
- Lines, planes, conics
- Distance, midpoint, slope
- Transformations: rotation, translation, scaling

## Key Methods
- Equation of line: y = mx + b, ax + by + c = 0
- Conic classification via discriminant
- Parametric curves
- Change of coordinates

## Canonical Examples
- Circle: (x-h)² + (y-k)² = r².
- Ellipse: x²/a² + y²/b² = 1.
- Distance from point to line: |ax₀+by₀+c|/√(a²+b²).

## Common Pitfalls
- Sign errors in distance formula
- Mixing polar and Cartesian
- Forgetting domain restrictions

## Related Skills
Linear Algebra, Calculus, Differential Geometry
