# Radiation from Accelerating Charges

**ID:** `em.radiation.accelerating_charges`  
**Domain:** Electromagnetism → Radiation  
**Difficulty:** 5/5

## Prerequisites
- em.waves.poynting

## Core Concepts
- Larmor formula
- dipole radiation
- retarded potentials
- antenna radiation

## Key Equations
$$
P = \frac{q^2 a^2}{6\pi\epsilon_0 c^3}\ \text{(Larmor)}
$$
$$
P = \frac{p_0^2\omega^4}{12\pi\epsilon_0 c^3}\ \text{(dipole)}
$$

## Methods
- Use Larmor for non-relativistic acceleration
- Use dipole approximation for oscillating charges
- Compute angular distribution of radiation

## Typical Problem Types
- Radiation from an antenna
- Synchrotron radiation
- Atomic transitions (semi-classical)

## Common Pitfalls
- Forgetting that only accelerated charges radiate
- Applying Larmor to relativistic cases
