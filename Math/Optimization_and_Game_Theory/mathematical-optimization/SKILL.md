# Optimization

## Domain
Finding extrema of functions.

## Core Concepts
- Convexity, duality
- Unconstrained vs. constrained
- Local vs. global optima
- KKT conditions

## Key Methods
- Gradient descent, Newton's method
- Lagrange multipliers
- Linear programming (simplex, interior point)
- Dynamic programming
- Stochastic gradient descent

## Canonical Examples
- Minimize f(x)=x² → x=0.
- LP: max cᵀx s.t. Ax≤b, x≥0.
- KKT for constrained smooth problems.

## Common Pitfalls
- Getting stuck in local minima
- Ignoring constraints' feasibility
- Divergence from bad learning rate

## Related Skills
Linear Algebra, Calculus, Machine Learning
