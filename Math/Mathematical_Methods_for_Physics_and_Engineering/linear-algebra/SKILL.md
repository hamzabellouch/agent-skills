# Linear Algebra

**ID:** `math.linear_algebra`  
**Domain:** Mathematics → Linear Algebra  
**Difficulty:** 2/5

## Prerequisites
- math.vectors.basics

## Core Concepts
- matrices
- eigenvalues/eigenvectors
- determinants
- orthogonality
- diagonalization

## Key Equations
$$
A\vec v = \lambda\vec v
$$
$$
\det(A-\lambda I) = 0
$$

## Methods
- Solve linear systems (Gaussian elimination)
- Find eigenvalues and eigenvectors
- Diagonalize when possible

## Typical Problem Types
- Systems of linear equations
- Normal modes
- Principal component analysis

## Common Pitfalls
- Assuming all matrices are diagonalizable
- Forgetting the normalization of eigenvectors
