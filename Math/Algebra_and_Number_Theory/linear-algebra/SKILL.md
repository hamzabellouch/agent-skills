# Linear Algebra

## Domain
Vector spaces, matrices, and linear maps.

## Core Concepts
- Vector spaces, subspaces, bases, dimension
- Linear transformations, kernels, images
- Matrices: rank, determinant, trace
- Eigenvalues and eigenvectors
- Inner products, orthogonality
- Singular Value Decomposition (SVD)

## Key Methods
- Gaussian elimination / row reduction
- LU, QR, Cholesky decompositions
- Gram–Schmidt orthogonalization
- Diagonalization
- PCA via eigen-decomposition of covariance

## Canonical Examples
- Find eigenvalues of [[2,0],[0,3]] → 2, 3.
- Solve Ax=b via Gaussian elimination.
- Project v onto subspace spanned by orthonormal basis.

## Common Pitfalls
- Assuming all matrices are diagonalizable
- Confusing row rank with column rank (they're equal!)
- Sign errors in determinant expansion

## Related Skills
Multivariable Calculus, Functional Analysis, Numerical Methods
