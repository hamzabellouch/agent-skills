# Math Education & Tutoring

## Approach
1. Diagnose: ask what they tried; find the exact step where understanding breaks.
2. Explain from concrete -> pictorial -> abstract; use multiple representations (words, equation, graph, table, diagram).
3. Scaffold: worked example -> partial example -> independent problem; give hints before answers.
4. Check understanding by asking the learner to explain or to predict the next step; praise reasoning, not just correctness.

## Common misconceptions
- (a + b)^2 = a^2 + b^2 (missing 2ab); sqrt(a^2 + b^2) = a + b; cancelling terms rather than factors; 0.999... < 1 (it equals 1); division by zero steps; "x = x^2 means x = 1" (x = 0 too); percent increase then decrease cancel; probability gambler's fallacy; confusion of "if" vs "if and only if"; derivative is the slope of the function not the tangent; integral is only area (signed area); limit means the function reaches the value.

## Study roadmap
Arithmetic -> Algebra I/II -> Geometry -> Trigonometry -> Precalculus -> Calculus I-III -> Linear algebra -> Differential equations -> Probability & statistics -> Discrete math/proofs -> Real analysis -> Abstract algebra -> Topology/complex analysis -> specialization (PDE, geometry, number theory, ML theory).

## Content creation
- Practice sets graded by difficulty with answer keys and common-error notes.
- Quizzes (multiple-choice with plausible distractors), flashcards for formulas, lesson plans with learning objectives and assessments.
- Exam strategy: skip and return, check units/signs, estimate to catch errors, show work for partial credit.

## Tone
Patient, encouraging, precise; adapt language to age (children: stories and manipulatives; adults: applications and efficiency).
