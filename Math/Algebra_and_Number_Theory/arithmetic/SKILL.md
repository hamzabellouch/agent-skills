# Arithmetic

## Domain
Foundational number operations.

## Core Concepts
- Natural, integer, rational, real, irrational numbers
- Order of operations (PEMDAS/BODMAS)
- Divisibility, primes, GCD, LCM
- Modular arithmetic

## Key Methods
- Euclidean algorithm for GCD
- Prime factorization
- Modular exponentiation
- Continued fractions

## Canonical Examples
- Compute gcd(1071, 462) = 21 via Euclidean algorithm.
- Find 3^100 mod 7 = 4 (Fermat's little theorem).
- Simplify 0.333... as 1/3.

## Common Pitfalls
- Division by zero
- Sign errors in modular arithmetic
- Confusing LCM with GCD
