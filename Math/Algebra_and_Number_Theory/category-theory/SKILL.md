# Category Theory

## Domain
Abstract structure of mathematical objects and morphisms.

## Core Concepts
- Categories, functors, natural transformations
- Limits, colimits
- Adjunctions
- Monads, monoids
- Topos theory

## Key Methods
- Universal properties
- Yoneda lemma
- Diagram chasing
- Kan extensions

## Canonical Examples
- Set is a category with functions as morphisms.
- Grp, Top, Vect are categories.
- Yoneda: Hom(Hom(A,-), F) ≅ F(A).

## Common Pitfalls
- Over-abstraction without examples
- Confusing covariant with contravariant
- Ignoring size issues (small vs. large categories)

## Related Skills
Abstract Algebra, Topology, Logic
