# Information Theory

## Domain
Quantifying information and uncertainty.

## Core Concepts
- Entropy H(X) = -Σ p log p
- Joint, conditional, mutual information
- KL divergence, cross-entropy
- Channel capacity
- Coding theory

## Key Methods
- Shannon's source coding theorem
- Huffman coding
- Noisy channel coding theorem
- Rate–distortion theory

## Canonical Examples
- Fair coin: H = 1 bit.
- Binary symmetric channel capacity: 1 - H(p).
- KL(P||Q) ≥ 0, equality iff P=Q.

## Common Pitfalls
- Confusing entropy with variance
- Using nats vs. bits inconsistently
- Ignoring channel model assumptions

Probability, Statistics, Machine Learning
