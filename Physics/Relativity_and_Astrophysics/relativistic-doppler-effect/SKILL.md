# Relativistic Doppler Effect

**ID:** `rel.special.doppler`  
**Domain:** Relativity → Special  
**Difficulty:** 4/5

## Prerequisites
- rel.special.time_dilation
- mech.waves.doppler

## Core Concepts
- redshift
- blueshift
- longitudinal/transverse Doppler
- cosmological redshift

## Key Equations
$$
f_{obs} = f_{src}\sqrt{\frac{1-\beta}{1+\beta}}\ \text{(receding)}
$$
$$
1+z = \frac{\lambda_{obs}}{\lambda_{src}}
$$

## Methods
- Decide receding vs approaching
- Use the relativistic formula for large eta
- Interpret redshift in cosmology

## Typical Problem Types
- Redshift of distant galaxies
- Doppler cooling of atoms
- Quasar spectra

## Common Pitfalls
- Using the classical formula for fast sources
- Confusing gravitational and kinematic redshift
