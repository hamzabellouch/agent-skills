# Lorentz Transformation

**ID:** `rel.special.lorentz`  
**Domain:** Relativity → Special  
**Difficulty:** 3/5

## Prerequisites
- rel.special.postulates
- mech.kinematics.relative

## Core Concepts
- Lorentz factor
- boost
- four-vectors
- rapidity
- Minkowski metric

## Key Equations
$$
\gamma = \frac{1}{\sqrt{1-\beta^2}}
$$
$$
x' = \gamma(x - vt),\ t' = \gamma(t - vx/c^2)
$$
$$
ds^2 = -c^2dt^2 + dx^2 + dy^2 + dz^2
$$

## Methods
- Apply the Lorentz transformation to events
- Use the invariant interval to compare frames
- Work with rapidity for successive boosts

## Typical Problem Types
- Event coordinates in two frames
- Velocity addition
- Invariant interval classification

## Common Pitfalls
- Using Galilean transform at high speed
- Forgetting the c² in the time equation
