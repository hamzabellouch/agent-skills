# Multivariable Calculus

## Domain
Calculus in ℝⁿ.

## Core Concepts
- Partial derivatives, gradients, directional derivatives
- Multiple integrals (double, triple)
- Line and surface integrals
- Divergence, curl, Laplacian
- Jacobian and change of variables

## Key Methods
- Lagrange multipliers for constrained extrema
- Green's, Stokes', and Divergence theorems
- Polar/spherical/cylindrical coordinates
- Hessian for second-order tests

## Canonical Examples
- ∇f for f(x,y)=x²y → (2xy, x²).
- ∬_D (x²+y²) dA over unit disk = π/2.
- Stokes: ∮ F·dr = ∬ (∇×F)·dS.

## Common Pitfalls
- Forgetting the Jacobian in substitutions
- Confusing divergence (scalar) with curl (vector)
- Boundary orientation errors in Stokes/Green

## Related Skills
Linear Algebra, PDEs, Differential Geometry
